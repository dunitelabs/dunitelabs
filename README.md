# Dunite Labs

Dunite Labs builds apps, websites and tools that solve real problems — Guava Music, Speedmaths Pro, GovtJobsNotice.

## Projects

- **Guava Music** — lightweight Android music player for offline listening.
- **Speedmaths Pro** — drill-based maths training for competitive exams.
- **Govt Jobs Notice** — clean, fast aggregator of government job notices.

## Commands

| Command          | Action                                      |
| :--------------- | :------------------------------------------ |
| `npm install`    | Installs dependencies                       |
| `npm run dev`    | Starts local dev server at `localhost:4321` |
| `npm run build`  | Build your production site to `./dist/`     |
| `npm run preview`| Preview your build locally, before deploying|

## Stack

Built with [Astro](https://astro.build). Vanilla CSS with a `data-theme` light/dark toggle.
